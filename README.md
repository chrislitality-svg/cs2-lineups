# CS2 战术沙盘

单文件 3D 网页应用，用于规划和复习 CS2 各地图的道具点位（烟/闪/火/雷）。基于 [three.js](https://threejs.org/)，全部逻辑、样式、交互都在一个 `index.html` 里。

线上：<https://www.huyicun.cloud/cs2/zs/>

## 功能

- **3D 沙盘**：每张地图渲染成俯视 3D 场景，可 WASD/拖拽巡视。
- **道具点位**：投掷点 → 爆开点的抛物线轨迹；支持**弹点/折点**（弹墙、折叠）和**弧线高低**手动调整。
- **同点位多道具**：一个站位下挂多颗道具，平级切换。
- **图片记录**：站位 / 瞄点 / 效果三张图，存浏览器 IndexedDB。
- **地名区域**：多边形区域 + 文字标签，文字/边界透明度可分别调、可批量改；顶点可拖，按住 Ctrl 点边线加节点。
- **出生点**：标注出生点，可直接当投掷点用。
- **自定义标签**：给道具打标签（自助闪 / 配合闪 …），可建可改可删。
- **云同步**：数据自动同步到自建后端，多设备实时一致（后端为独立服务，不在本仓库内）。
- **备份**：一键导出 / 导入完整数据（含图片 base64）。

## 运行

纯静态，无需构建。本地起任意静态服务器即可：

```bash
python -m http.server 3456
# 浏览器打开 http://localhost:3456/
```

## 结构

```
index.html        # 整个应用（HTML + CSS + JS 单文件）
imgs/             # 道具图标 + 背景图
maps/             # 各地图俯视贴图（{地图名}.webp）
```

## 部署

把 `index.html` + `imgs/` + `maps/` 上传到任意静态目录即可（纯静态，覆盖生效）。
